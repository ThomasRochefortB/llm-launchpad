# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| `0.0.x` | Yes |
| `< 0.0.2` | No |

## Reporting a Vulnerability

Do not open a public GitHub issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting flow for this repository when it is
available. Include:

- a clear description of the issue and impacted components
- reproduction steps or a proof of concept
- any known mitigation or workaround
- your preferred contact details for follow-up

If private reporting is unavailable in the repository UI, contact the maintainer
through the email address published in the package metadata and avoid public
disclosure until a fix is available.

## Response Expectations

- Initial acknowledgement within 5 business days
- Status updates at least weekly for confirmed issues
- Coordinated disclosure after a fix or mitigation is ready
